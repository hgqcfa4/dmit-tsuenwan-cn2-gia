## 三网 CN2 GIA 具体是怎么走的

这是买这款机器最该看的部分。DMIT 香港 Pro 系列的线路结构大致是：

- **回程**：三网都经香港 CTG 汇聚，接国内电信 CN2 GIA（AS4809）
- **电信去程**：CN2 GIA 直连香港 CTG
- **联通去程**：AS4837 + AS10099（联通国际精品网）
- **移动去程**：香港 CMI（AS58453）直连

把它和香港另外两条产品线放一起，区别就清楚了：

| 产品线 | 线路定位 | 大陆访问优化 |
| --- | --- | --- |
| Premium（HKG.Pro，含荃湾） | 三网回程 CTG + CN2 GIA | 有，三网 |
| Eyeball（HKG.EB） | 回程三网 CMI，去程电信/联通走 CTG GIA | 有，偏移动 |
| Tier 1（HKG.AS3.T1） | 纯国际 BGP，无中国方向优化 | 基本没有 |

T1 便宜是便宜（年付 $36.9 起），但它不针对大陆做优化，晚高峰绕行是常态。如果你的用途本身就是国内访问，荃湾所在的 Pro 线才是对的那个抽屉。

值得一提的是，DMIT 香港 Pro 的常规机型后来整体免费升级到了 AMD EPYC 9005（内部简称 AN5），官方口径是加量不加价。特价款的硬件平台请以下单页当时显示的为准，这类信息变动比价格还快。

## 荃湾和常规 Pro 怎么选

如果你的需求是「一台年付、能长期放着、国内访问稳定」的小机器，荃湾这款的性价比在 DMIT 香港 Pro 里确实突出：同样的 500G 流量，年付总价 $259.9，比 TINY 月付一年便宜了将近一半，硬盘还多一倍。

但有三件事得接受：

**端口只有 500Mbps。** 常规 Pro 是 1Gbps。日常建站、API、中转基本感受不到差别，但如果你要跑大流量的直播中转或者长时间满速下载，这 500Mbps 就是天花板。

**限量款会售罄。** DMIT 的特价款不是长期在架商品，卖完下架、补货时间不定，这是它一贯的节奏。想买的时候可能刚好没货，这一点没有太多办法。

**必须年付。** 想先月付试水的，只能从 TINY 起步。

反过来说，如果你的预算能到 $79.9/月，STARTER 给到 2G 内存和 1T 流量，1Gbps 端口，长期跑业务的余量会舒服很多。而如果你只需要一台便宜的国际线路机器、国内访问快慢无所谓，T1.WEE 年付 $36.9 才是真·入门价，别在 Pro 线里纠结。

**500GB 月流量够用吗？**
建站、跑 API、面板管理这类用途绰绰有余。如果是视频中转或者大文件分发，先算一下日均消耗再决定。
